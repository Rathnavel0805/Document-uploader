DOCUMENT UPLOADER - quick start

1. Install Node.js (LTS) from https://nodejs.org
2. Install MySQL Community Server + MySQL Workbench from https://dev.mysql.com/downloads/
3. In MySQL Workbench, open setup.sql and run it (lightning bolt button).
4. Open settings.js and put your MySQL password.
5. Open a terminal in this folder and run:   npm install
6. Then run:                                  node server.js
7. Open http://localhost:3000 in your browser.
